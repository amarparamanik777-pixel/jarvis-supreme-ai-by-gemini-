# JARVIS Supreme AI — Native Android App for Redmi Note 15 5G (8GB / 256GB)

This repository contains the complete, production-ready native Kotlin Android application for **JARVIS Supreme AI**, plus an automated **GitHub Actions Cloud APK Builder** (`.github/workflows/build-apk.yml`) so you can compile and download the installable `.apk` directly on your **Redmi Note 15 5G** without needing a PC.

## How to Get Your Installable `.apk` on Your Phone (Zero PC Required, 100% Official & Stable)

1. Open **github.com** in Chrome on your Redmi Note 15 5G and sign in (free account).
2. Tap **+** -> **New repository**, name it `jarvis-android-ai`, set it to **Private**, and tap **Create repository**.
3. Upload the files from this project folder (or import the repository), making sure the `.github/workflows/build-apk.yml` file is included.
4. Tap the **Actions** tab at the top of your GitHub repository -> tap **Build Jarvis Android APK (No-PC Cloud Builder)** -> tap **Run workflow**.
5. In ~2 minutes, GitHub's official cloud servers compile your native Android source code into `Jarvis-RedmiNote15-APK.zip`. Tap it to download `app-debug.apk` directly onto your Redmi Note 15 5G and tap **Install**!
